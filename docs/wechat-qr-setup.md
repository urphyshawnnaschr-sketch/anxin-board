# 微信扫码接收正式报告

安心看板直接管理微信连接，客户无需另装或启动 OpenClaw。正式报告按内容分页，发送为微信聊天中的图片；接收后直接查看，不必打开报告网页。

## 第一次绑定

1. 从桌面“安心看板”快捷方式启动，进入项目的安心看板页面。
2. 点击“绑定微信”，用准备接收报告的微信扫描页面中的二维码，并在手机上确认。微信要求配对码时按页面提示由本人填写。
3. 页面显示微信已绑定后，打开当前正式确认的报告，生成图片预览，核对全部图片和接收人，再确认发送。无需先向 ClawBot 发消息。

二维码在短时间后过期；过期后手动重新获取。关闭页面或取消后，旧绑定流程不能继续覆盖新配置。绑定不会自动发送报告，也不会自动回复微信消息或调用大模型。

只有完成扫码的微信账号可作为这次绑定的收件人。其他人或群聊的消息不会更改收件人。页面只接收建立会话所需的标识和上下文，不保存聊天正文。

## 已绑定与连接失效

连接和令牌由安心看板保存在本机 Windows 凭据管理器，令牌不显示在页面，也不进入项目数据库、报告或普通备份。换电脑时重新绑定。

“刷新会话（可选）”用于手动更新已有微信会话，不是首次发送的前置步骤。若微信明确拒绝发送，可向 ClawBot 发一条消息后刷新会话；登录已失效时重新扫码。刷新或恢复绑定不会自动重发报告，历史发送记录继续保留。已经提交、部分提交或结果未知时，先核对微信中实际收到的图片，不要重复发送。

“解除本机绑定”停止安心看板使用该连接并清理对应可用凭据。它不会删除历史发送记录，也不表示已经替你撤销微信服务器或其他软件中的绑定。

## 已有 OpenClaw

扫码直接绑定与原 OpenClaw 登录能否同时使用，腾讯客户端公开实现没有保证。若同一个微信正被其他软件使用，重新绑定可能影响原连接。要继续复用原部署，可打开高级选项并依照 [现有 OpenClaw 接入说明](wechat-openclaw-setup.md) 配置。

## 收件验收

“已提交微信”说明接口返回发送结果，不能替代手机收件确认。应在微信中逐页核对图片数量、顺序、中文、书法图和模型信息；部分失败和结果未知均不会自动重试。开发中的合成接口测试、图片截图测试和安装检查，不属于真实微信收件证据。

协议依据为腾讯官方插件 2.4.9 固定提交 `24de5c9eb0dd5e595d7e2d090ed8a3f82870d42c` 的 [公开协议](https://github.com/Tencent/openclaw-weixin/blob/24de5c9eb0dd5e595d7e2d090ed8a3f82870d42c/docs/protocol.md)。实际账号是否开放 ClawBot、手机端登录是否有效，以微信显示为准。
